# Experiments

Each experiment is a numbered folder `exp_NNN/`:

```
experiments/exp_NNN/
  HYPOTHESIS.md   written BEFORE the experiment
  FINDINGS.md     written AFTER, including negative results
  (scripts, measurements, optional screenshots/recordings)
```

Keep raw artifacts small; ignore large frames/recordings via `.gitignore` and
link to them from `FINDINGS.md` with the command and numbers used. Every
keep/drop decision is logged in `../../ARCHITECTURE_LOG.md`.
